# aracrypt-enctool

By Bayu Surya Arafah | Aracrypt - File Encryption Tool adalah aplikasi GUI berbasis Python yang digunakan untuk mengenkripsi dan mendekripsi file menggunakan algoritma AES-GCM 256-bit. Aplikasi ini menyediakan antarmuka pengguna yang intuitif untuk mengamankan file dengan passphrase yang kuat.
